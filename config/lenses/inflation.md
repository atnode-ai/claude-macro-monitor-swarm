# Inflation lens (CPI, PPI, PCE)

- Core matters more than headline for the Fed. The mandate gauge is **2% core PCE y/y**.
- PPI leads CPI by 1 to 3 months; ISM Prices Paid leads PPI. CPI is the biggest single market mover on release day; PCE is usually partly priced because it follows CPI.
- Materiality: core m/m off consensus by 0.1pp or more, or any print that shifts the Fed-path narrative.
- Playbook: hotter than expected means yields up, equities down, USD up, cuts pushed back (or hikes pulled forward). Cooler is the reverse.
- Watch the gap between core PCE and core CPI (composition and weights differ), and annual BEA revisions that move y/y levels without any fresh cooling.
- Consensus: one targeted search for the Reuters/Bloomberg/Dow Jones poll for the reference month. Prefer m/m and y/y for headline and core.
